|---|---|---|---|

- このフォルダの音源は、作曲者の Clarinet_Express 様が信町高速鉄道のために作り、使用の許可をいただいたものです。
- ゲームのほかの部分（プログラム・絵・合成した効果音）とは別の扱いです。**このゲーム以外の作品に流用したり、音源だけを取り出して配ったりしないでください。** 使いたいときは、作曲者に直接許可をもらってください。
- ファイルは Scratch のプロジェクトにあったものをそのまま置いています。ジェネレータ（`generator/assets.py` の `melody`）が `.sb3` に入れるときに、3 曲の音量だけをそろえます。
